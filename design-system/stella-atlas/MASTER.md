# Stella Atlas — game identity and wiki layout

## Reference evidence (October 23, 2026)
- Official site: https://stellasora.global/
- Official stylesheet: https://novaweb-usstatic.yo-star.com/h5/assets/main-cf08def8.css
- Stylesheet font declarations include Poppins Regular, Oswald Regular/Bold, NovaModern and several CJK fonts. Use Poppins for English text and Oswald for headings. These are verified official website fonts; in-client usage has not been verified. Font files are locally hosted from the exact declared official URLs.
- Observed official CSS colors: cyan #0ABEC5, indigo #4B5082, gold #FFDE6D, pale blue #C6D6E6. Adapted text cyan #06777D improves light-background readability. Neutral backgrounds extend the official pale-blue appearance.
- Prydwen https://www.prydwen.gg/star-rail: persistent grouped navigation and direct database shortcuts.
- Kaiden https://www.kaiden.gg/stella-sora/: compact game banner, section navigation and grouped guide/character modules.

## Decisions
Keep English and all 54 separate pages. Persistent desktop wiki sidebar, mobile top navigation, compact art banner and immediately visible database shortcuts. Remove broad promotional copy. Keep existing character data, personal ranks and local favorites unchanged. No implied meta rankings or new unverified builds.

## Typography and interaction
Local font faces with swap and primary font preloads. Headings use Oswald, body/control text uses Poppins. Cyan for indicators, indigo for text/actions, pale blue for surfaces, yellow for rank accents. Keyboard focus remains visible. Reduced-motion rules retained. Guide cards and directory controls retain explicit text labels and accessible names.
